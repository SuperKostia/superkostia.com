## The pitch

On 1 June 2026, the Choose France summit at Versailles announced **71
foreign investments, €93 billion, more than 15,600 jobs**. It was all in a
45-page press kit PDF: impossible to read if you want to decide where to
look.

This project turns the PDF into an interactive map dashboard: every
investment project is geolocated down to the site (the factory, not just
the town), with a circle sized by the amount invested.

## What you can do with it

- **Projects view**: one circle per site, sized on a log scale of CAPEX (from
  €2M to €75bn, you need it), coloured by sector family.
- **Regions view**: amounts aggregated by administrative region.
- **Progress view**: projects recoloured by phase (announced, studies, permit
  granted, works started, operational), to see at a glance what's actually
  moving.
- **Filters** by sector family, free search, a detailed card per project with
  the investor's track record in France.
- A detour to **Kourou** for PLD Space's launch pad, the only project outside
  mainland France.

## How it's made

The whole data pipeline is the work of a fleet of AI agents orchestrated in
three waves:

1. **Extraction**: the press kit read in parallel, coverage checked against
   the official list of 71 announcements, deduplication.
2. **Enrichment**: one agent per project checks every field against the
   source and searches the web for the investor's existing presence in
   France.
3. **Geocoding**: one agent per project pins the exact site (the former
   Bridgestone plant in Béthune, the converted air base of E-Valley in
   Cambrai...), with geometric safeguards and corrective retries.

The output is a single HTML file with no framework: MapLibre GL JS for the
map, [OpenFreeMap](https://openfreemap.org/) vector tiles (free, no API key,
in the spirit of this site), data embedded as JSON.
